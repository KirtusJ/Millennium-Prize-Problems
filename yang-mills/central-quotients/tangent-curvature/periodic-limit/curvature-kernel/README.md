## A conditional Wasserstein statement before taking a subsequence

Write $h=\beta^{-1/2}$, $Y$ for the interior curvature tuple, $Y_s$ for the shell tuple and $\mathcal E$ for the sigma algebra generated by all adapted exterior curvatures. Let $G(s)$ denote the law of the linear face curl in the Dirichlet Gaussian with shell **potential** $s$, and $\mathsf L$ the shell left inverse. For every real $1\le p<\infty$, using Euclidean distance on the finite face tuple,
$$
\lim_{\beta\to\infty}\ \sup_{\mu\in\mathcal L_\beta}
\mathbb E_\mu\!\left[W_p^p\big(\mathcal L_\mu(Y\mid\mathcal E),G(\mathsf L Y_s)\big)\right]=0.
$$
This compares kernels within each finite-coupling state. The random shell input can change with the state.

## An event that separates the two curvature laws exactly

Every linear-curl Gaussian output has $d_cY=0$ identically, for every choice of shell input, since $d^2=0$.

In the nonlinear law the conditional probability of $d_cY=0$ is zero. Indeed, relative to twelve independent Haar links the Wilson marginal of these free edges is absolutely continuous for every fixed exterior. Consider first product Haar. Off the cut points, the squared length of the additive sum is real analytic in each individual link. With other links fixed, at most two points of that link’s $S^3$ make an incident face equal to $-I$; nonincident faces are off their cuts almost surely. The complement of these points in $S^3$ is connected. Its analytic zero set is therefore null or the whole domain. Thus resampling one Haar link leaves the event indicator unchanged almost surely. Resampling all twelve successively produces an independent copy with the same indicator. Its probability equals its square.
