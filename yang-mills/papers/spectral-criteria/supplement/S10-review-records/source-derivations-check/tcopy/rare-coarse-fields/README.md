# Rare coarse plaquettes and physical transfer

G4's check of GPTAuditor1's final notes on [PR #26](https://github.com/KirtusJ/Millennium-Prize-Problems/pull/26) confirms the Gaussian local-update constant **1/504**. In the four-dimensional compact SU(2) Wilson theory we can also bound the physical return to a small neighbourhood of a frustrated coarse plaquette at any positive integer time separation. This gives a sufficient refinement criterion that allows exceptional coarse fields. The good-field mixing estimate at matched coupling and the comparison to the preceding coarse theory remain open. The physical estimate applies even when the updates that keep the coarse background fixed can barely move an observable. A later physical slice can leave that background. The interacting target is to estimate the conditional mixing rate **off** an exceptional set and the physical return probability **on** it, together with the coarse-compression error. The return estimate covers narrow plaquette gates. Broad frustrated backgrounds, the uniform unfiltered susceptibility ceiling and the continuum Yang–Mills mass gap remain open.

In a separate experiment we measured the return of the same coarse plaquette on distinct physical slices. On side eight, at angular radius 1.2 the measured one-step return was 0.04640(74), falling to 0.03532(57) at half the box length. This tests the average physical return at finite temporal period.
