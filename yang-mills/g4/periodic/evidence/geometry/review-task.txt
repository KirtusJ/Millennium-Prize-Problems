## Split kernel and normalization

Write \(U_c(x)=U(c)(x)\), \(a=\operatorname{src}(c)\), and \(b=\operatorname{dst}(c)\). On \(X\times G^B\), define
\[
M_c(x,p)=\rho\!\left(p_a U_c(x)p_b^{-1}\right).
\]
Cyclicity of trace and unitarity give, for \(h_v=p_v^{-1}q_v\),
\[
\operatorname{ReTr}\bigl(M_c(x,p)M_c(y,q)^*\bigr)
=\operatorname{ReTr}\rho\!\left(
U_c(x)h_b U_c(y)^{-1}h_a^{-1}\right).
\]
For independent \(p,q\) with law \(m^B\), conditional on \(p\) the variable \(h=p^{-1}q\) has law \(m^B\). This change of variables leaves \(s(x)\), \(s(y)\), and the observable untouched.

Let \(\Phi(x,p)\) concatenate the real and imaginary entries of each \(M_c(x,p)\), scaled by \(\sqrt{\beta_c}\). The split crossing factor is \(e^{\Phi(x,p)\cdot\Phi(y,q)}\). With \(d\nu(x,p)=e^{s(x)}\,d\mu(x)\,dm^B(p)\), the unnormalized reflected expectation is
\[
\begin{aligned}
N_F
&=\iint \overline{F(x)}F(y)
  e^{\Phi(x,p)\cdot\Phi(y,q)}\,d\nu(x,p)\,d\nu(y,q)\\
&=\sum_{n=0}^{\infty}\frac{1}{n!}
  \left\|\int F(x)\Phi(x,p)^{\otimes n}\,d\nu(x,p)\right\|^2
  \ \ge 0 .
\end{aligned}
\]
The exponential series converges absolutely and uniformly because the features are bounded. Compactness and continuity bound the original real exponent, so \(0<Z=N_1<\infty\), the normalized tilted measure is a probability, and \(N_F/Z\ge 0\). The same proof gives positive semidefiniteness of every finite Gram matrix of the Haar-projected kernel by replacing the half integral with a finite weighted sum.

The original involution is \((x,y,h)\mapsto(y,x,h^{-1})\), with inversion componentwise. Each crossing word goes to a cyclic permutation of its inverse, which preserves the real trace. Haar inversion preserves the reference measure. This proves the reflected inequality for the stated class of half observables \(F(x)\), with no gauge-invariance premise on \(s\) or \(F\).

## Period-two four-edge sign cycle

Use \(G=\{\pm1\}\) with the sign representation, uniform independent reference links, \(s=0\), and common coupling \(\beta\). Write \(\chi(x)=\prod_{e=0}^3x_e\) and \(t=\tanh\beta\). Expanding the four plaquette factors in one seam, the Haar average keeps the empty edge set and the full cycle. All other edge subsets contain a vertex with odd incidence, whose sign averages to zero. The two seams therefore give
\[
K(x,y)=\cosh^8\beta\,\bigl(1+t^4\chi(x)\chi(y)\bigr)^2 .
\]
In the uniform-measure kernel operator on the 16 spatial configurations, the constant and \(\chi\) eigenvalues are respectively \(\cosh^8\beta(1+t^8)\) and \(2\cosh^8\beta\,t^4\). The other 14 eigenvalues are zero. Thus zeros occur even at \(\beta=.8\).

A negative-coupling control is to flip the sign of exactly one plaquette coupling in **each** seam. The projected kernel then has \(1-t^4\chi(x)\chi(y)\) in place of the positive-sign factor. Its quadratic value on \(F=\chi\) is \(-2\cosh^8\beta\,t^4<0\) for \(\beta=.8\). Flipping one plaquette in just one seam of this symmetric example would give a constant kernel and miss the failure.

After dividing each reference-measure partition function by the common \(\cosh^8\beta\), the projected value is \(1+t^8\). Setting every temporal link to \(1\) gives \((1+t^2)^4\), since each spatial edge then has an independent sign product with weight \(e^{2\beta x_e y_e}\). Flipping all four temporal links on one seam leaves the physical plaquette weight invariant and reverses the Polyakov sign at every vertex. The physical Polyakov moment is consequently \(0\), while in the all-ones model it is \(1\).

The script enumerates both independent temporal layers by convolving their one-seam sums. The observable-weighted one-seam sums give the Polyakov numerator, and the spatial parity gives the Gram quadratic check.

```python
from itertools import product
from math import cosh, exp, fsum, isclose, prod, tanh

beta = 0.8
configs = tuple(product((-1, 1), repeat=4))
next_vertex = (1, 2, 3, 0)
scale = cosh(beta) ** 8


def seam_average(edge_products, couplings, polyakov_factor=False):
    terms = []
    for temporal in configs:
        exponent = sum(
            coupling * edge_sign * temporal[a] * temporal[b]
            for a, (b, edge_sign, coupling) in enumerate(
                zip(next_vertex, edge_products, couplings)
            )
        )
        observable = temporal[0] if polyakov_factor else 1
        terms.append(observable * exp(exponent))
    return fsum(terms) / len(configs)


def close(actual, expected):
    assert isclose(actual, expected, rel_tol=1e-12, abs_tol=1e-12), (
        actual, expected
    )


positive = (beta,) * 4
negative_control = (-beta, beta, beta, beta)
projected_weights = []
naive_weights = []
polyakov_weights = []
positive_quadratic = []
negative_quadratic = []

for x, y in product(configs, repeat=2):
    edge_products = tuple(a * b for a, b in zip(x, y))
    parity = prod(edge_products)
    seam = seam_average(edge_products, positive)
    seam_with_sign = seam_average(edge_products, positive, polyakov_factor=True)
    seam_negative = seam_average(edge_products, negative_control)
    projected_weights.append(seam**2)
    naive_weights.append(exp(2 * beta * sum(edge_products)))
    polyakov_weights.append(seam_with_sign**2)
    positive_quadratic.append(parity * seam**2)
    negative_quadratic.append(parity * seam_negative**2)

pair_count = len(configs) ** 2
projected_ratio = fsum(projected_weights) / pair_count / scale
naive_ratio = fsum(naive_weights) / pair_count / scale
projected_polyakov = fsum(polyakov_weights) / fsum(projected_weights)
naive_polyakov = fsum(naive_weights) / fsum(naive_weights)
q_positive = fsum(positive_quadratic) / pair_count / scale
q_negative = fsum(negative_quadratic) / pair_count / scale

t = tanh(beta)
close(projected_ratio, 1 + t**8)
close(naive_ratio, (1 + t**2) ** 4)
close(projected_polyakov, 0.0)
close(naive_polyakov, 1.0)
close(q_positive, 2 * t**4)
close(q_negative, -2 * t**4)

print("Normalized partition functions", projected_ratio, naive_ratio)
print("Polyakov moments", projected_polyakov, naive_polyakov)
print("Normalized parity quadratics", q_positive, q_negative)
```
